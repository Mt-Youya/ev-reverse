## 已做的缓解：别名表

改名前，这一集的本地文件与稿件里的分P 标题对不上，会让上传逻辑每轮都把它当成「缺失」，
于是要么永远 `--skip 前端工具链`（watchdog 之前就是这么绕的），要么每轮补一个重复分P。
现在 `tools/bili_upload.py` 里记了一条别名：

```python
PART_ALIASES = {"前端工具链": {"01. 课程概述.mp4": "前端工具链"}}
```

于是它被正确判为「已在稿件里」。**人工改名后请删掉这条别名**，并去掉 watchdog 里可能残留的
`--skip`。

## 为什么现在不能自动修

B站 稿件管理页的「编辑」「⋮」按钮对合成点击无响应（Playwright 真实点击、hover、原始鼠标事件都试过，
坐标换算已核对），所以**不能在页面上拖拽重排分P**。API 删除接口 `member.bilibili.com/x/vu/web/delete`
返回 404，新 endpoint 未找到。

改名/重排的 API 也走不通：`member.bilibili.com/x/vu/web/edit` 对 GET 返回 **405**，只接受 POST，
且要带整份 archive 载荷（`videos` 数组里每个分P 的 `filename` 必须是上传时的存储名）。**手写这份载荷
有破坏线上稿件的风险，所以没有做。** 上面「需要人工做的」那节是替代方案。

## Comments

**2026-10-13 — 改名做完了，重排还开着。**

「合成点击对编辑页无响应」这个前提已经不成立：agent-browser + CDP 能驱动这张页面，
同一天用同一条路给 Electron 加了 20 个分P、给另外三门课追加了分P、还删掉了
`工程管理实战` 里两条重复分P（issue 02）。所以「只能人工」的说法只对**拖拽重排**这一条成立。

改名怎么做的（脚本 `.scratch/rename-part.mjs`，可复用）：

1. 打开 `?type=edit&bvid=BV1zqhb6bE1W`；
2. 分P 标题不是输入框，是 `div.pure-text.pure-text-editable`（`cursor: pointer`），**先点它**；
3. 点完那个元素会被换掉，所以字段要**按它持有的值**去找（新出现的 input 里装的就是旧标题）；
4. 用原生 setter 写值 + `input`/`change` 事件，回车提交；
5. 点「立即投稿」保存。

关键细节：`01. ESLint介绍` 在稿件里出现了**两次**，所以脚本按「第 N 次出现」定位 ——
第 1 次是套着错误标题的课程概述（2342 秒），第 3 个分P 才是真的 ESLint 引言（1864 秒）。
只有第 1 次要改。改错了就是把两节课的名字对调。
